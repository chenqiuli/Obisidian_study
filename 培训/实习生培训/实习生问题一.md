- 路由传参：
- 1、query 路由传参：带在url路径的问号后面。在跳转的时候直接在问号后面进行传参，多个参数用&分割，比如：`/general/customer/customerEdit?status=edit&id=${record.id}`
```tsx
import { useLocation } from 'umi';
const location = useLocation();
const queryParams = new URLSearchParams(location.search);
const id = queryParams.get('id');
const prospectId = queryParams.get('prospectId');
```
- 2、动态路由传参：是在路由表里面的path配置，使用冒号变量的方式，比如:id。获取的时候使用useParams()的方式
![](Pasted%20image%2020251119161612.png)
```tsx
import { useParams } from 'umi';
const { id } = useParams();
```

##### Git拉取项目、提交代码 完整流程：
- 本地新建一个空文件夹，命名必须是英文，用来存放克隆的远程仓库
- 在这个空文件夹内使用powerShell或git bash，执行 git clone 远程http的路径
- cd 进去这个仓库，
- 看项目要求，目标分支是哪个，把dev分支的代码同步到本地：git pull origin dev
- 安装依赖 ：pnpm i
- 使用cd命令或者在vscode直接终端打开，apps/mobile 路径下pnpm dev
- 写了很多代码，有了很多改动的文件 ....... 
- git checkout -b XXX 【新建一个本地分支，用名字拼音】
- git add . 
- git commit -m"feat: YYY"  【双引号内的文案必须是以feat或者fix开头的，但是要注意这两个单词后面要加英文冒号还有一个空格，YYY是你们本次改动的修改日志】
- git pull origin dev 【这时候可能会出现一些冲突，比如：别人跟你同时改动到了同一个文件，这时候你要解决冲突。用VScode解决冲突，必要时刻与他们沟通。解决完冲突之后，相当于你的本地又有了一些改动，要重新执行add、commit、pull】
- git push origin XXX
